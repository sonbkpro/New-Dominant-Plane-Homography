# PLAN_TIP: Conditional Flow-Matching Dominant-Plane Support And Reliability For TIP-Level Homography Estimation

Authoring goal:
This file is a complete implementation blueprint for Claude or another coding agent.
It upgrades the current `new_approach` implementation into a stronger IEEE TIP submission candidate.

Important scope rule:
Ignore the older `plan.txt`. This document is based on the current New Approach and on `plan_new.txt`,
but it changes the scientific framing from "replace HomoGAN's GAN mask" to:

    Learn dominant-plane support with a conditional flow model, validate whether its
    samples form a real posterior or only a disagreement estimate, use the support
    for robust homography projection, and estimate when the single-homography model
    should be trusted or rejected.

The implementation must keep the current codebase usable while adding TIP-level novelty.
Do not delete the current flow-matching implementation immediately. Extend it.


================================================================================
0. Executive Summary
================================================================================

The existing New Approach already implements the engineering baseline:

    image pair
      -> featureHomo shallow features
      -> transformerHomo dense homography-induced flow
      -> conditional flow-matching mask module
      -> masked homography alignment loss

This is a good engineering replacement for HomoGAN's adversarial mask.
However, for IEEE TIP, this alone is probably not novel enough because prior work already covers:

1. content-aware masks for homography,
2. dynamic object masks for homography,
3. dominant-plane/coplanarity masks with GANs,
4. pseudo plane masks and multi-homography estimation,
5. transformer and recurrent refinement for homography.

The upgraded TIP-level method should therefore be:

    Conditional Flow-Matching Dominant-Plane Support And Reliability

Short method name suggestion:

    DPC-Homo

or, if emphasizing the flow model:

    FlowDPC-Homo

Core idea:

    Do not treat the flow-matching mask as a deterministic attention mask.
    Treat it as a conditional support distribution over the dominant-plane
    support, and call it a posterior only if the training objective supplies
    genuine conditional ambiguity:

        p_theta(M | I_a, I_b, H_0, R, C)

    where:

        M   = dominant-plane support mask,
        I_a = first image,
        I_b = second image,
        H_0 = initial homography-induced flow or matrix,
        R   = residual evidence after warping,
        C   = bidirectional/cycle consistency evidence.

Then use this support distribution or validated posterior to compute:

1. mean support map,
2. sample variance / ambiguity or disagreement map,
3. entropy map,
4. robust weighted DLT projection,
5. pair-level reliability score,
6. invalid single-homography detection.

This changes the paper's claim from:

    "We use flow matching to predict masks."

to:

    "We formulate unsupervised homography estimation as dominant-plane support
    consensus with reliability estimation, where a conditional flow model represents
    either a validated posterior or an empirically calibrated disagreement signal."


0.1 Critical Corrections From Review
------------------------------------

This plan must not assume that noisy flow-matching sampling automatically creates
calibrated posterior uncertainty.

With one deterministic target mask per condition, rectified or conditional flow
matching learns a field that transports every source sample toward the same target
mask in the ideal limit. Under that training setup, K-sample variance is mostly
finite-capacity, finite-step, or injected-noise disagreement. It is not a
principled posterior by construction.

Therefore:

1. Use the word "posterior" only for the multimodal-target or latent-variable
   version described below.
2. If multimodal targets are not implemented, call K-sample variance "sample
   disagreement" and calibrate it empirically against reprojection error.
3. Run the K-sample variance/disagreement versus error experiment before using
   "posterior" in the paper title, abstract, or contribution list.
4. Treat weighted DLT as robust projection from one global basis-flow field, not
   as multi-plane reasoning or a major standalone novelty.
5. Center the paper on reliability, abstention, and invalid single-homography
   detection. Support masks and robust DLT are mechanisms that make this possible.


================================================================================
1. What Must Be Novel
================================================================================

1.1 Novelty Target
------------------

The paper should claim novelty in the following combination:

1. A conditional flow-matching support model that becomes a true posterior only
   when trained with multimodal or latent-variable targets.
2. A geometry-coupled source path from crude residual consensus to refined support,
   instead of generic Gaussian-noise-to-mask generation.
3. Mean support, entropy, and empirically validated variance/disagreement statistics.
4. Uncertainty-aware robust DLT projection from dense flow using support weights
   and diagnostics.
5. Pair-level reliability prediction for detecting invalid single-homography cases.
6. A TIP-grade evaluation protocol including accuracy, calibration, failure detection,
   risk-coverage, runtime, and stress tests.

The most important novelty is not the U-Net, the transformer, or the fact that the
mask is learned. The novelty is reliability-aware dominant-plane support consensus
with validated uncertainty or calibrated disagreement.


1.2 Claims To Avoid
-------------------

Do not claim:

1. "We are the first to use masks for homography."
2. "We are the first to handle dynamic objects in homography."
3. "We are the first to estimate the dominant plane."
4. "We are the first to use transformers for homography."
5. "We are the first to estimate multiple planes."
6. "Flow matching itself is new."

Instead claim:

1. Flow matching is used to model conditional geometric support.
2. Multimodal or latent training is required before calling sample variance a posterior.
3. The method estimates not only a homography, but also where it is valid and
   whether it is reliable.
4. The method can abstain or down-rank image pairs where a single homography is
   physically invalid.


1.3 Reviewer-Facing One-Sentence Contribution
---------------------------------------------

Suggested one-sentence contribution:

    We propose a conditional flow-matching dominant-plane support model that converts
    residual geometric evidence into validated support distributions or calibrated
    disagreement maps, enabling robust projection and reliability estimation for
    unsupervised deep homography in multi-plane and dynamic scenes.

3. New Method Overview
================================================================================

3.1 High-Level Pipeline
-----------------------

The upgraded model should run:

    Input pair:
        I1, I2

    Step 1: Initial homography flow
        HNet predicts dense flows:
            F_12 or H_flow_b depending on existing convention
            F_21 or H_flow_f depending on existing convention

    Step 2: Warp evidence
        Warp images and features using initial flow.
        Compute feature residuals, image residuals, flow magnitude, and cycle cues.

    Step 3: Crude geometric consensus seed
        Convert residuals into a seed support logit map:
            z_seed = residual_consensus_logits(...)

    Step 4: Conditional flow-matching support distribution
        Sample N support masks:
            M_k ~ p_theta(M | condition, z_seed)

        Compute distribution statistics:
            q_mean = mean_k M_k
            q_var  = var_k M_k
            q_ent  = entropy(q_mean)

        Interpret q_var as posterior uncertainty only after multimodal or
        latent-variable training and empirical calibration. Otherwise interpret
        it as sample disagreement.

    Step 5: Trusted support
        Combine forward/backward posterior support:
            trusted_img1 = q1_mean * warp(q2_mean)
            trusted_img2 = q2_mean * warp(q1_mean)

    Step 6: Robust homography projection
        Fit a robust projected homography from the single global dense flow
        using support weights:
            H_projected = weighted_DLT(flow, support_weight)

    Step 7: Reliability prediction
        Predict scalar reliability:
            s = P(single dominant homography is valid)

    Step 8: Output
        Return:
            dense flows,
            projected homographies,
            mean support maps,
            uncertainty or disagreement maps,
            reliability score,
            diagnostic statistics.

3.3 Posterior Or Disagreement Statistics
----------------------------------------

For sampled masks:

    samples: [B, K, 1, H, W]

Compute:

    q_mean = samples.mean(dim=1)
    q_var  = samples.var(dim=1, unbiased=False)
    q_ent  = -q_mean * log(q_mean) - (1 - q_mean) * log(1 - q_mean)

Expected behavior after the multimodal/latent posterior fix:

1. the residual evidence is ambiguous,
2. multiple planes explain different parts of the image,
3. the mask boundary is unclear,
4. dynamic foreground occupies large support,
5. the initial homography is compromised.

If the model is trained with one deterministic target per condition, these
statistics are not a principled posterior. In that case:

    q_mean = mean support
    q_var  = sample disagreement
    q_ent  = support entropy

The manuscript may call q_var "uncertainty" only if it is empirically calibrated
against reprojection error and the wording makes clear that it is calibrated
disagreement, not a formal posterior.


3.4 Reliability Definition
--------------------------

The reliability score should mean:

    reliability = P(the pair admits a useful single dominant homography)

It is not semantic correctness.
It is not mask IoU.
It is not inverse of loss only.

A pair is reliable if:

1. there is a sufficiently large dominant support region,
2. residual inside support is low,
3. forward/backward support is consistent,
4. validated uncertainty or calibrated disagreement is not excessive,
5. weighted DLT is numerically stable,
6. estimated H has reasonable forward/backward agreement,
7. point errors or synthetic known errors are expected to be below a threshold.

6.1 Initial Homography Flow
---------------------------

Keep the existing transformer flow prediction.

Inputs:

    img1_patch_fea
    img2_patch_fea

Existing computation:

    forward_fea = cat([img1_patch_fea, img2_patch_fea], dim=1)
    weight_f = h_net(forward_fea)
    H_flow_f = sum(basis * weight_f)

    backward_fea = cat([img2_patch_fea, img1_patch_fea], dim=1)
    weight_b = h_net(backward_fea)
    H_flow_b = sum(basis * weight_b)

Do not change this in the first implementation.
All novelty should be added after the initial flow is predicted.


6.2 Residual Evidence
---------------------

For image 1 frame:

    feature_residual_1 = mean(abs(img1_patch_fea - warp_img2_patch_fea), dim=1, keepdim=True)
    image_residual_1   = mean(abs(img1_patch     - warp_img2_patch),     dim=1, keepdim=True)

For image 2 frame:

    feature_residual_2 = mean(abs(img2_patch_fea - warp_img1_patch_fea), dim=1, keepdim=True)
    image_residual_2   = mean(abs(img2_patch     - warp_img1_patch),     dim=1, keepdim=True)

Robust normalization:

    r_norm = (r - median(r)) / (MAD(r) + eps)

Combine:

    residual = w_feature * r_feature_norm + w_image * r_image_norm

Default:

    w_feature = 0.7
    w_image   = 0.3


6.3 Geometry-Coupled Consensus Seed
-----------------------------------

The current `plan_new.txt` uses:

    x0 = Gaussian noise or zero logits
    x1 = target mask logits

For TIP novelty, add a geometry-coupled path:

    x0 = z_seed + sigma * epsilon
    x1 = target support mask logits

where:

    z_seed = residual_to_seed_logits(residual)

Define:

    seed_prob = sigmoid((tau - residual_norm) / temperature)
    z_seed    = logit(clamp(seed_prob, eps, 1 - eps))

The flow model therefore learns:

    crude residual consensus -> refined support

instead of:

    noise -> mask

This is a key scientific distinction, but it does not by itself create a
posterior. With one target mask per condition, the learned flow should collapse
toward that one target. A posterior interpretation requires the multimodal or
latent-variable target mechanism in Section 8.6.

6.6 Flow-Matching Support Model
-------------------------------

Keep the existing class name:

    DominantMaskFlow

But add support-sampling methods. Name the methods `sample_posterior` for API
continuity only if Section 8.6 is implemented; otherwise document their output
as repeated support samples and sample disagreement.

Required new method:

    def sample_logits(
        self,
        cond: torch.Tensor,
        steps: int = 1,
        solver: str = "euler",
        init: str = "seed_noise",
        source_logits: torch.Tensor | None = None,
        noise_scale: float = 1.0,
        requires_grad: bool = False,
    ) -> torch.Tensor:
        ...

Behavior:

    init == "zero":
        z = zeros

    init == "noise":
        z = noise_sigma * randn

    init == "seed":
        z = source_logits

    init == "seed_noise":
        z = source_logits + noise_scale * randn

Return:

    final logits z_1, not sigmoid mask.

Then update old `sample`:

    logits = sample_logits(...)
    return sigmoid(logits / temperature)


6.7 Support Sampling / Posterior API
------------------------------------

Add:

    def sample_posterior(
        self,
        cond: torch.Tensor,
        num_samples: int = 8,
        steps: int = 1,
        solver: str = "euler",
        init: str = "seed_noise",
        source_logits: torch.Tensor | None = None,
        noise_scale: float = 1.0,
        requires_grad: bool = False,
        return_logits: bool = True,
    ) -> dict:
        ...

Return dict:

    {
        "samples":        [B, K, 1, H, W],
        "logits_samples": [B, K, 1, H, W],
        "mean":           [B, 1, H, W],
        "var":            [B, 1, H, W],
        "entropy":        [B, 1, H, W],
        "sample_entropy": scalar or [B],
    }

Implementation detail:

    The simplest implementation loops over K samples.
    Later optimize by expanding batch:

        cond_rep = cond.repeat_interleave(K, dim=0)
        source_rep = source_logits.repeat_interleave(K, dim=0)
        logits_rep = sample_logits(cond_rep, ...)
        logits = logits_rep.view(B, K, 1, H, W)

Use batch expansion first if memory allows.

Interpretation rule:

    If `target_modes` or latent/dropout training is enabled, `var` may be treated
    as posterior uncertainty after calibration.

    If the model is trained with one deterministic target per condition, `var`
    must be treated as sample disagreement and must not be the sole basis of a
    posterior claim.

Pseudo-code:

    x1 = logits_from_mask(target_mask)
    x0 = source_logits + noise_sigma * torch.randn_like(source_logits)
    t = Uniform(t_min, 1)
    xt = (1 - t) * x0 + t * x1
    target_velocity = x1 - x0

Return:

    xt, t, target_velocity

This is the training path that should be emphasized in the paper.


6.9 Support Weight From Mean And Validated Uncertainty
------------------------------------------------------

Use mean support and either validated uncertainty or calibrated disagreement to
build robust DLT projection weights.

Function:

    support_weight_from_posterior(
        mean: torch.Tensor,
        var: torch.Tensor | None = None,
        residual: torch.Tensor | None = None,
        min_weight: float = 1e-4,
        variance_weight: float = 1.0,
        residual_weight: float = 0.0,
    ) -> torch.Tensor

Recommended:

    weight = mean

If variance is available:

    weight = mean / (1 + variance_weight * var)

If residual is available:

    weight = weight * exp(-residual_weight * residual_norm)

Clamp:

    weight = weight.clamp(min_weight, 1.0)

Use this for weighted DLT.


6.10 Uncertainty-Aware Robust DLT Projection
--------------------------------------------

The current `flow_mask_to_homography` can already convert flow plus mask to H.
For TIP, extend it or add a new function:

    posterior_flow_to_homography(
        flow,
        support_weight,
        uncertainty=None,
        normalize_points=True,
        return_diagnostics=True,
    )

Preferred implementation:

    Put the robust implementation in `new_approach/geometry_homo.py`
    or a new `new_approach/geometry_tip.py`.

Important framing:

    The current homography network predicts one global 8-basis flow field.
    This module does not estimate multiple homographies and does not reason over
    multiple planes explicitly. It selects/reweights the dominant support and
    projects the single global flow into a numerically robust homography matrix.

Important improvements over current `flow_mask_to_homography`:

1. Normalize point coordinates before DLT.
2. Return DLT condition diagnostics.
3. Return number/effective number of support points.
4. Return support area.
5. Return fallback flag.
6. Optionally use top-k support points for speed.
7. Optionally remove very low weights.

Weighted normalized DLT outline:

    points src: (x, y)
    points dst: (u, v) = (x + flow_x, y + flow_y)
    weights w_i

    Normalize src and dst:
        src_norm, T_src = normalize_points(src)
        dst_norm, T_dst = normalize_points(dst)

    Build A:
        [-x, -y, -1,  0,  0,  0, u*x, u*y, u]
        [ 0,  0,  0, -x, -y, -1, v*x, v*y, v]

    Multiply rows by sqrt(w_i).

    Solve:
        Ah = 0 by SVD.

    Denormalize:
        H = inv(T_dst) @ H_norm @ T_src

    Normalize:
        H = H / H[2, 2]

Optional second-stage refinement:

Add params:

Start with:

7. Losses

7.1 Existing Losses To Keep

7.2 Geometry-Coupled Flow Matching Loss
---------------------------------------

File:

    new_approach/losses_tip.py

Function:

    geometry_coupled_flow_matching_loss(
        mask_flow,
        cond,
        target_mask,
        source_logits,
        confidence=None,
        noise_sigma=0.5,
        t_min=1e-4,
    )

Pseudo-code:

    z_t, t, target_v = make_geometry_coupled_flow_matching_batch(
        target_mask=target_mask,
        source_logits=source_logits,
        noise_sigma=noise_sigma,
        t_min=t_min,
    )

    pred_v = mask_flow(z_t, t, cond)
    loss = (pred_v - target_v)^2

    if confidence is not None:
        loss = loss * confidence

    return loss.mean()

This should become the main support-model training loss.


7.3 Mean Support Supervision
----------------------------

Use when synthetic or pseudo target masks are available.

Function:

    posterior_mask_supervision_loss(support_samples_or_posterior, target_mask, confidence=None)

Components:

    BCE(mean, target)
    Dice(mean, target)

Recommended:

    loss = 2.0 * BCE + 1.0 * Dice

Apply confidence weighting for pseudo targets.


7.4 Support Consistency Loss
----------------------------

Purpose:

    Forward and backward mean supports should agree after warping.

Given:

    q1 = img1_mask_mean
    q2 = img2_mask_mean
    warp_q1_to_2 = warp_img1_mask_mean
    warp_q2_to_1 = warp_img2_mask_mean

Loss:

    L_cons =
        mean(abs(q2 - warp_q1_to_2) * valid_2)
      + mean(abs(q1 - warp_q2_to_1) * valid_1)

Optional uncertainty-aware weighting:

    disagreement_weight = 1 / (1 + var1 + warped_var2)

Then:

    L_cons = mean(disagreement_weight * abs(...))


7.5 Uncertainty-Weighted Alignment Loss
---------------------------------------

Upgrade the existing masked triplet alignment to use mean support and validated
uncertainty or calibrated disagreement.

For each pixel:

    q_i     = support probability
    sigma_i = spatial uncertainty, validated posterior std, or calibrated disagreement proxy
    r_i     = feature residual

Use:

    weight_i = q_i / (sigma_i^2 + eps)

If no learned sigma:

    sigma_i^2 = variance_or_disagreement_i + sigma_floor

Loss:

    L_align = sum(weight_i * triplet_i) / (sum(weight_i) + eps)

Optional likelihood form:

    L = sum(q_i * (r_i / sigma_i + log(sigma_i))) / (sum(q_i) + eps)

First implementation:

    Use uncertainty/disagreement-weighted triplet loss only after the correlation
    with reprojection error is validated. Otherwise use q_i as the weight and
    keep variance/disagreement for reliability diagnostics.


7.6 Support Area Prior
----------------------

Keep current area loss, but apply to mean support:

    min_area = 0.10
    max_area = 0.95

Use dataset-specific values:

    Real outdoor/indoor video:
        min_area = 0.15
        max_area = 0.95

    Synthetic with large distractors:
        min_area = 0.10
        max_area = 0.90

Do not make area too restrictive.
The method should be allowed to say that a single homography is unreliable.
If support is tiny, reliability should go down rather than forcing the mask larger.


7.7 Support Sharpness And Diversity
-----------------------------------

Avoid forcing all samples to be identical too early.

Use two separate ideas:

1. Mean mask entropy:

       entropy(q_mean)

   Minimize only after warmup if masks are too soft.

2. Sample diversity:

       var(samples)

   Do not always minimize. Variance is useful only if multimodal/latent training
   makes it meaningful or if empirical calibration shows it tracks error.

Recommended:

    For synthetic valid pairs with known clean masks:
        lightly minimize variance near confident target areas.

    For invalid or ambiguous pairs:
        allow high variance.

Optional loss:

    target_confidence = abs(target_mask - 0.5) * 2
    L_var = mean(target_confidence * posterior_var)

Use this only for synthetic/pseudo high-confidence labels.


7.8 Reliability Loss
--------------------

Reliability target options:

1. Binary valid/invalid label:

       y_valid in {0, 1}
       L_rel_bce = BCEWithLogits(reliability_logit, y_valid)

2. Soft quality target from known or pseudo error:

       y_quality = exp(-error / tau_error)
       L_rel_reg = SmoothL1(reliability, y_quality)

3. Brier score:

       L_brier = mean((reliability - y_valid)^2)

Recommended:

    Synthetic invalid training:
        BCE + Brier

    Real validation/calibration:
        quality regression if point error labels exist

Combined:

    L_rel = lambda_rel_bce * BCE + lambda_brier * Brier + lambda_quality * SmoothL1


7.9 Invalid Pair Margin Loss
----------------------------

For invalid pairs:

    reliability should be low,
    support should not be overconfident,
    residual inside support should not be falsely low.

Loss:

    L_invalid =
        relu(reliability - invalid_max_score)^2
      + relu(mean_support - invalid_max_support_if_no_dominant)^2 optional

Do not always punish support on invalid pairs.
Some invalid pairs still contain a dominant local plane, but the full single homography may be bad.
The safer target is reliability, not mask area.


7.10 Robust Projection Loss
---------------------------

If ground-truth or validation point correspondences are available in synthetic data:

    H_projected should be better than H_initial.

Loss:

    L_project = corner_error(H_projected, H_gt)

or:

    L_project = reprojection_error(points, H_projected)

For unsupervised real data:

    Use residual after projected warp:

    L_project_unsup =
        uncertainty_weighted_alignment_loss(after projected warp)

First implementation can skip differentiating through DLT if unstable:

    detach H_projected for reliability diagnostics,
    use mean support masks for loss weighting.


7.11 Full Loss By Stage
-----------------------

Stage A: Homography pretraining

    L = L_align_unmasked + L_FIL

Stage B: Synthetic posterior pretraining

    L =
        lambda_fm      * L_geometry_coupled_fm
      + lambda_bce     * L_posterior_bce
      + lambda_dice    * L_posterior_dice
      + lambda_area    * L_area
      + lambda_tv      * L_tv
      + lambda_var     * L_var_confident

Stage C: Real pseudo posterior training

    L =
        lambda_fm      * L_geometry_coupled_fm_pseudo
      + lambda_bce     * L_posterior_bce_pseudo
      + lambda_dice    * L_posterior_dice_pseudo
      + lambda_cons    * L_posterior_consistency
      + lambda_area    * L_area
      + lambda_tv      * L_tv

Stage D: Joint posterior consensus fine-tuning

    L =
        lambda_align   * L_uncertainty_weighted_alignment
      + lambda_fil     * L_FIL
      + lambda_fm      * L_geometry_coupled_fm_if_targets_available
      + lambda_cons    * L_posterior_consistency
      + lambda_area    * L_area
      + lambda_tv      * L_tv
      + lambda_entropy * L_entropy_after_warmup

Stage E: Reliability training/calibration

    L =
        lambda_rel_bce     * L_reliability_bce
      + lambda_brier       * L_brier
      + lambda_quality     * L_quality_regression
      + lambda_invalid     * L_invalid_margin

Stage F: End-to-end TIP fine-tune

    L =
        Stage D loss
      + small Stage E reliability loss

8. Synthetic TIP Dataset
================================================================================

8.1 Purpose
-----------

The existing `Data/synthetic_flow_mask_dataset.py` creates synthetic masks.
For TIP novelty, add `Data/synthetic_tip_dataset.py` with valid and invalid pair labels.

The reliability head needs training data that includes cases where single homography
is valid and cases where it is invalid.


8.2 Dataset Outputs
-------------------

Each synthetic sample should return:

    imgs_gray_patch:       [2, H, W]
    imgs_gray_full:        [2, H, W] or same as patch
    dominant_flow:         [2, H, W] or [H, W, 2]
    img1_dominant_mask:    [1, H, W]
    img2_dominant_mask:    [1, H, W]
    H_gt:                  [3, 3] optional
    is_valid_homography:   scalar 0/1
    reliability_target:    scalar in [0, 1]
    invalid_type:          string or integer id
    dominant_area:         scalar
    synthetic_error_gt:    optional scalar
    start:                 compatible tensor
    pts:                   compatible tensor


8.3 Synthetic Case Types
------------------------

Generate at least these types.

Type 0: Clean valid homography

    One image patch warped by one known homography.
    No outlier.

    is_valid_homography = 1
    reliability_target = 1

Type 1: Valid dominant plane with small dynamic/outlier objects

    Apply H_dom to the background.
    Paste 1 to 3 small moving objects or CutMix regions.
    Dominant area > 0.65.

    is_valid_homography = 1
    reliability_target around 0.8 to 1.0

Type 2: Valid but difficult low texture

    Apply blur, brightness shift, noise, low contrast.
    Homography still valid if enough structure remains.

    is_valid_homography = 1
    reliability_target depends on texture score.

Type 3: Multi-plane but dominant plane exists

    Background uses H_dom.
    One large region uses H_out.
    Dominant area 0.45 to 0.70.

    is_valid_homography = 1 if H_dom support remains large and well distributed.
    reliability_target 0.5 to 0.8.

Type 4: Ambiguous multi-plane

    Two or three planes with similar support area.
    No clear dominant plane.

    is_valid_homography = 0
    reliability_target 0.0 to 0.4.

Type 5: Dominant foreground motion false support

    Large moving foreground occupies central region.
    Background is small or split.

    is_valid_homography = 0 or low reliability.

Type 6: Non-homographic deformation

    Apply elastic deformation, rolling-shutter-like skew, or piecewise local warp.

    is_valid_homography = 0
    reliability_target 0.0 to 0.3.

Type 7: Repeated texture / correspondence ambiguity

    Use repeated patterns, grid textures, or tiled crops.

    is_valid_homography can be 1 geometrically but reliability should be lower
    if evidence is ambiguous.

Type 8: No overlap or severe occlusion

    Very small overlap or large pasted occluders.

    is_valid_homography = 0
    reliability_target 0.0.


8.4 Reliability Target Design
-----------------------------

For synthetic data:

    If H_gt exists, compute expected corner or grid error after the estimated or
    initial homography.

But before model prediction, define target from generation metadata:

    base_valid = 1 for clear dominant H, 0 otherwise
    area_score = clamp((dominant_area - min_area) / (good_area - min_area), 0, 1)
    texture_score = normalized gradient magnitude
    ambiguity_penalty = 1 - plane_area_margin_score
    occlusion_penalty = outlier_area

Example:

    reliability_target =
        base_valid
      * area_score
      * texture_score
      * plane_margin_score
      * overlap_score

Clamp to [0, 1].

Important:

    This synthetic reliability target is a training signal, not proof of physical
    calibration. Final reliability claims must be validated against real
    coordinate-label reprojection error on held-out Coordinate-v2 pairs.


8.5 Synthetic Mask Targets
--------------------------

For valid dominant plane cases:

    target mask = dominant plane support.

For invalid ambiguous cases:

    target mask can still identify the largest support plane,
    but reliability target should be low.

This distinction is important:

    Mask answers "where is the best dominant support?"
    Reliability answers "is a single homography trustworthy?"


8.6 Multimodal Targets For A Real Posterior
-------------------------------------------

This section is mandatory if the paper uses the word "posterior" as a headline
claim.

Problem:

    If each condition has exactly one target mask, conditional flow matching
    learns a deterministic transport to that target. Sampling different x0 values
    does not create a real posterior in the ideal training limit.

Required multimodal solution:

1. For ambiguous synthetic Type 3 and Type 4 pairs, generate two or three planar
   regions with similar support area and plausible residual evidence.
2. Store every plausible support mask:

       target_masks: [K_modes, 1, H, W]
       target_flows: [K_modes, 2, H, W] optional
       mode_validity: [K_modes]

3. During training, sample one mode index per item:

       mode_idx ~ Categorical(mode_weights)
       target_mask = target_masks[mode_idx]

4. Keep the visible image pair and condition as similar as possible across modes.
   The ambiguity should come from multiple plausible dominant supports, not from
   changing the image so much that each mode is a different condition.
5. Train the flow model so different latent/noise samples can map to different
   plausible support masks.
6. Evaluate whether generated samples recover multiple modes:

       mode coverage,
       best-of-K IoU,
       sample diversity,
       variance/error correlation,
       reliability on ambiguous pairs.

Alternative latent-variable solution:

    If true same-condition multimodal data is too hard to generate, concatenate
    a low-dimensional latent code z or use MC-dropout/ensembles. Then call the
    output a latent support distribution or ensemble disagreement, not a pure
    flow-matching posterior, unless calibration experiments justify the stronger
    wording.

Fallback:

    If neither multimodal targets nor latent/dropout/ensemble uncertainty is
    implemented, remove "posterior" from the method name and contribution claims.
    Use "conditional support model" and "calibrated sample disagreement" instead.

9.1 Basic Pseudo Mask

    pseudo_2_warped_from_1 = warp(pseudo_1_raw)

    pseudo_2 = pseudo_2_raw * pseudo_2_warped_from_1


9.2 Pseudo Confidence
---------------------

Confidence should be high when:

1. pseudo mask is far from 0.5,
2. forward/backward pseudo masks agree,
3. residual inside support is lower than outside,
4. support area is not degenerate,
5. validated uncertainty or calibrated disagreement from the current model is low.

Compute:

    confidence_pixel = abs(pseudo - 0.5) * 2

Then multiply by:

    bidirectional_agreement

Optional:

    confidence_pixel *= exp(-posterior_var)


9.3 Reject Bad Pseudo Labels
----------------------------

Reject a pseudo mask pair if:

    mean_support < pseudo_min_area
    mean_support > pseudo_max_area
    confidence.mean < pseudo_min_confidence
    residual_gap < pseudo_min_residual_gap

Where:

    residual_gap = residual_outside_mean - residual_inside_mean

Default:

    pseudo_min_area = 0.10
    pseudo_max_area = 0.95
    pseudo_min_confidence = 0.25
    pseudo_min_residual_gap = 0.05


9.4 Real Reliability Pseudo Targets
-----------------------------------

If point annotations are available for validation/training:

    error = point matching error or corner error
    reliability_target = exp(-error / tau_error)

If not:

    reliability_pseudo =
        support_score
      * residual_gap_score
      * bidirectional_score
      * dlt_condition_score
      * low_uncertainty_score

Do not over-trust real pseudo reliability.
Use lower loss weight than synthetic reliability.

    warp_img1_patch, warp_img2_patch
    H_flow_f, H_flow_b

    if self.mask_method == "flow_matching":

        # 1. Build residual seeds.
        seed_logits_1, seed_prob_1, seed_stats_1 = residual_consensus_seed(
            reference_feature=img1_patch_fea,
            warped_feature=warp_img2_patch_fea,
            reference_image=img1_patch,
            warped_image=warp_img2_patch,
            tau=params.mask_seed_tau,
            temperature=params.mask_seed_temperature,
            close_kernel=params.mask_seed_close_kernel,
        )

        seed_logits_2, seed_prob_2, seed_stats_2 = residual_consensus_seed(
            reference_feature=img2_patch_fea,
            warped_feature=warp_img1_patch_fea,
            reference_image=img2_patch,
            warped_image=warp_img1_patch,
            tau=params.mask_seed_tau,
            temperature=params.mask_seed_temperature,
            close_kernel=params.mask_seed_close_kernel,
        )

        # 2. Build condition tensors.
        img1_mask_cond = build_mask_condition_v2(..., seed_prob=seed_prob_1, seed_logits=seed_logits_1)
        img2_mask_cond = build_mask_condition_v2(..., seed_prob=seed_prob_2, seed_logits=seed_logits_2)

        # 3. Support sample count.
        K = params.mask_posterior_train_samples if self.training else params.mask_posterior_eval_samples

        # 4. Sample support masks.
        #    These are posterior samples only when multimodal/latent training is enabled.
        post1 = self.mask_flow.sample_posterior(
            img1_mask_cond,
            num_samples=K,
            steps=params.mask_flow_steps,
            solver=params.mask_flow_solver,
            init=params.mask_flow_source,
            source_logits=seed_logits_1,
            noise_scale=params.mask_flow_noise_scale,
            requires_grad=params.mask_flow_sample_grad,
        )

        post2 = self.mask_flow.sample_posterior(
            img2_mask_cond,
            num_samples=K,
            steps=params.mask_flow_steps,
            solver=params.mask_flow_solver,
            init=params.mask_flow_source,
            source_logits=seed_logits_2,
            noise_scale=params.mask_flow_noise_scale,
            requires_grad=params.mask_flow_sample_grad,
        )

        # 5. Mean masks keep existing output semantics.
        img1_patch_mask = post1["mean"]
        img2_patch_mask = post2["mean"]

        # 6. Warp mean supports.
        warp_img1_patch_mask = get_warp_flow(img1_patch_mask, H_flow_b, start)
        warp_img2_patch_mask = get_warp_flow(img2_patch_mask, H_flow_f, start)

        # 7. Trusted support.
        trusted_f, trusted_b = bidirectional_posterior_consensus(...)

        # 8. Support weights for DLT.
        support_weight_f = support_weight_from_posterior(...)
        support_weight_b = support_weight_from_posterior(...)

        # 9. Initial and robust projected H.
        H_f_initial = flow_mask_to_homography(H_flow_f, None)
        H_b_initial = flow_mask_to_homography(H_flow_b, None)

        if params.use_posterior_refinement:
            H_f_refined, dlt_stats_f = posterior_flow_to_homography(H_flow_f, support_weight_f)
            H_b_refined, dlt_stats_b = posterior_flow_to_homography(H_flow_b, support_weight_b)
        else:
            H_f_refined = H_f_initial
            H_b_refined = H_b_initial

        # 10. Reliability.
        reliability_features = build_reliability_feature_vector(...)
        rel = self.reliability_head(reliability_features)

        reliability_logit = rel["logit"]
        reliability = rel["score"]

14.0 Mandatory Killer Ablations
-------------------------------

Run these before building the full paper story. They decide whether the method
can honestly claim posterior consensus or must be reframed as calibrated support
disagreement.

1. Residual seed only vs full flow model:

       If seed-only is nearly equal to the full model, the flow module is not
       earning its complexity. The paper must then emphasize reliability and
       abstention, not mask-generation novelty.

2. Noise-to-mask vs seed-to-mask:

       Compare generic x0 ~ noise against geometry-coupled x0 = seed + noise.
       The geometry-coupled path must improve mask quality, homography error, or
       reliability metrics.

3. K=1 vs K=8 with variance/disagreement correlation to reprojection error:

       Compute Spearman/Pearson correlation, error bins, ROC-AUC for failure, and
       risk-coverage. If K-sample variance does not track error, call it sample
       disagreement only and remove posterior claims.

17. Expected Failure Modes And Fixes
================================================================================

17.1 Support Samples Collapse To Same Mask
------------------------------------------

Cause:

    source noise too small,
    loss over-penalizes variance,
    deterministic seed dominates.

Fix:

    increase mask_flow_noise_scale,
    reduce lambda_posterior_var,
    use K>1 during training,
    add ambiguous synthetic cases,
    add true multimodal targets if a posterior claim is needed.


17.2 Variance Or Disagreement High Everywhere
---------------------------------------------

Cause:

    flow model undertrained,
    source seed too noisy,
    pseudo labels inconsistent.

Fix:

    train longer on synthetic_tip,
    reduce source noise,
    filter pseudo labels more aggressively,
    increase support BCE/Dice weights.


17.3 Reliability Always High
----------------------------

Cause:

    invalid synthetic pairs too easy or underrepresented,
    reliability loss too weak,
    reliability features missing validated uncertainty/disagreement.

Fix:

    balance valid/invalid batches,
    increase lambda_reliability_bce,
    include error-based soft targets,
    add ambiguous multi-plane cases.


17.4 Reliability Always Low
---------------------------

Cause:

    invalid cases dominate,
    pseudo targets too pessimistic,
    support area priors too strict.

Fix:

    balance dataset,
    use known valid clean homographies,
    reduce invalid margin weight,
    recalibrate with validation set.


17.5 Homography Worsens After Refined DLT
-----------------------------------------

Cause:

    mask weights select wrong region,
    weighted DLT unstable,
    support too concentrated spatially.

Fix:

    require support spatial spread,
    fallback to initial H if DLT condition is poor,
    blend weights with uniform:

        weight = alpha * posterior_weight + (1 - alpha) * uniform

    start alpha at 0.5.


17.6 Area Loss Fights Reliability
---------------------------------

Cause:

    invalid pairs may naturally have small support.

Fix:

    do not force large masks on invalid pairs,
    condition area loss on valid pairs or high pseudo confidence,
    rely on reliability score for invalidity.

18. Paper Positioning
================================================================================

18.1 Proposed Title
-------------------

Possible titles:

1. Conditional Flow-Matching Dominant-Plane Support for Trustworthy Homography Estimation
2. Reliability-Aware Dominant-Plane Consensus for Unsupervised Deep Homography Estimation
3. FlowDPC-Homo: Flow-Matching Support Consensus for Reliable Homography Estimation

Use a title containing "posterior" only if the multimodal-target or latent
posterior path passes the required K-sample uncertainty experiments.


18.2 Abstract Skeleton
----------------------

Problem:

    Deep homography estimators often force an image pair into a single projective
    transform even when parallax, dynamic objects, occlusion, or multiple planes
    violate the model assumption.

Gap:

    Existing mask-based methods suppress outliers, but usually produce a single
    deterministic support map and do not quantify support ambiguity or pair-level
    reliability.

Method:

    Propose a conditional flow-matching model that transports crude residual
    consensus into a dominant-plane support distribution. If multimodal targets
    are used, this distribution is treated as a posterior; otherwise its sample
    variance is calibrated as disagreement. Use mean support and validated
    uncertainty/disagreement for robust DLT projection. Predict reliability for
    single-homography validity.

Results:

    Improve homography accuracy, failure detection, calibration, and risk-coverage
    under multi-plane/dynamic stress tests.


18.3 Contribution Bullets
-------------------------

Suggested paper contributions:

1. We formulate unsupervised deep homography estimation as reliability-aware
   dominant-plane support consensus rather than deterministic mask prediction.

2. We introduce a geometry-coupled conditional flow-matching model that maps
   residual consensus seeds to a support distribution, with a multimodal-target
   option for a true posterior interpretation.

3. We use mean support and validated uncertainty/disagreement statistics for
   robust DLT projection and bidirectional consensus.

4. We predict pair-level reliability for detecting invalid single-homography cases
   and evaluate calibration through risk-coverage and failure-detection metrics.

5. We provide extensive ablations and stress tests covering parallax, dynamic
   objects, low texture, repeated patterns, and ambiguous multi-plane scenes.


18.4 Strongest Reviewer Defense
-------------------------------

If a reviewer says:

    "This is just another mask."

Answer:

    The method does not only output a deterministic mask. It models a conditional
    support distribution, validates whether its samples behave as posterior
    uncertainty or calibrated disagreement, uses the resulting support in robust
    projection, and predicts pair-level validity. The evaluation includes
    calibration and failure detection, which deterministic mask baselines cannot
    provide without additional modeling.

If a reviewer says:

    "Flow matching is not new."

Answer:

    The novelty is not generic flow matching. The novelty is a geometry-coupled
    path from residual consensus to dominant-plane support, integrated with robust
    projection and reliability estimation. Posterior language is used only when
    multimodal or latent training makes it defensible.

If a reviewer says:

    "Multi-homography methods already handle multiple planes."

Answer:

    This work targets reliable single dominant homography estimation with explicit
    validity and calibrated uncertainty/disagreement. It is complementary to
    multi-homography methods and addresses when a single homography should be
    trusted or rejected. It does not claim multi-plane estimation.

4. Robust weighted DLT projection improves or at least does not degrade average accuracy.
5. Reliability score separates successful and failed homographies.
6. Risk-coverage curve is clearly better than confidence baselines.
7. Runtime overhead is acceptable or one-step distillation is shown.
8. Ablations prove each novelty component.
9. Qualitative figures show meaningful uncertainty/disagreement on ambiguous regions.
10. The paper does not claim novelty in masks alone or multi-plane estimation.

================================================================================
22. Final Implementation Philosophy
================================================================================

The engineering principle:

    Add support sampling, validated uncertainty/disagreement, and reliability
    around the existing New Approach.
    Do not rewrite the homography transformer unless necessary.

The scientific principle:

    Every new module must support the TIP claim:

        dominant-plane support,
        validated uncertainty or calibrated disagreement,
        robust DLT projection,
        reliability,
        failure detection.

If a proposed component does not help one of those five claims, defer it.

The first successful milestone is not a perfect paper result.
The first successful milestone is:

	    current model forward pass
	      -> residual seed
	      -> K support samples
	      -> mean support and variance/disagreement
	      -> robust projected H
	      -> reliability score
      -> all shapes correct
      -> no NaNs
      -> one backward step works.

After that, train and evaluate the components stage by stage.
