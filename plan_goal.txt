# PLAN_GOAL: Accuracy-First Upgrade of new_approach to Beat RealSH (0.34 PME) on Data/Test_List.txt

Authoring goal:
This file is a complete, self-contained implementation blueprint for a coding agent
(Codex) to upgrade the EXISTING `new_approach` codebase so that its point-matching
error (PME) on Data/Test_List.txt drops below RealSH's 0.34 average.

This plan is intentionally DIFFERENT from plan_TIP.txt.
  - plan_TIP.txt is a *reliability / trustworthiness* plan. It does not lower PME.
  - THIS plan is an *accuracy* plan. Every component must reduce PME.

Scope of this plan = recommendations (1), (3), (4), (5) from the review:
  (1) Iterative residual refinement of the homography estimator   <-- biggest lever
  (3) Scaled training (capacity, batch, iterations, LR schedule)
  (4) Keep + sharpen the dominant-plane mask (loss + DLT weighting)
  (5) Target the SF (small-foreground) category specifically

EXPLICITLY OUT OF SCOPE (recommendation (2), excluded by request):
  - RealSH-style realistic *supervised* data generation (generating GT homographies
    to train a supervised corner-error loss).
  Rationale: we keep the method UNSUPERVISED. An unsupervised method (CodingHomo,
  0.31) already beats RealSH (0.34), so supervised data generation is not required
  to reach the target, and avoiding it keeps the contribution positioning clean
  ("unsupervised, beats a supervised SOTA"). Synthetic *mask* supervision and
  unsupervised foreground augmentation (Section 8) are NOT recommendation (2) and
  ARE in scope: they never use a ground-truth homography.

Golden rule for the agent:
  Do NOT rewrite new_approach. ADJUST it. Preserve all existing output-dict keys and
  the evaluate.py / Data loader contracts. Land changes in stages, each behind a flag,
  each measured against PME before proceeding.

4. CORE UPGRADE (1) -- ITERATIVE RESIDUAL REFINEMENT
================================================================================

Idea: replace the single h_net call per direction with T iterations that re-warp the
target features by the current accumulated flow and predict a RESIDUAL basis-flow.
This is the RAFT/IHN/RHWF recipe expressed in the existing 8-basis representation, so
it reuses gen_basis, get_warp_flow, and flow_mask_to_homography unchanged.

4.1 New params (add in default_homo_params at train_new.py:32 and evaluate.default_params)
  refine_iters:            int  = 4        # T outer iterations (1 == current behavior)
  refine_detach_between:   bool = True     # stop-grad on the flow used to re-warp (RAFT-style)
  refine_supervision:      bool = True     # apply triplet loss at every iteration
  refine_gamma:            float= 0.8      # RAFT weighting: w_t = gamma^(T-1-t)
  refine_share_weights:    bool = True     # reuse the single h_net across iterations (recommended)

4.2 Add a helper in HomoNet (transformerHomo.py), used for BOTH directions.

  def _estimate_flow_iter(self, fea_ref, fea_tgt, h_patch, w_patch):
      """
      fea_ref, fea_tgt: [B, C_fea, h_patch, w_patch]  (C_fea==1 in core path)
      returns: flow [B,2,h_patch,w_patch], inter_flows: list[[B,2,h,w]]  (len == refine_iters)
      """
      bs = fea_ref.shape[0]
      iters = int(_param(self.params, "refine_iters", 1))
      detach_between = _param_bool(self.params, "refine_detach_between", True)
      basis = self.basis.to(fea_ref.device)            # [1, num_basis, 2*h*w]
      weight_total = 0
      flow = None
      inter_flows = []
      for t in range(iters):
          if t == 0:
              tgt_warp = fea_tgt
          else:
              warp_flow = flow.detach() if detach_between else flow
              tgt_warp = get_warp_flow(fea_tgt, warp_flow)        # start=0 at patch res
          delta = self.h_net(torch.cat([fea_ref, tgt_warp], dim=1))   # [B, num_basis, 1]
          weight_total = weight_total + delta
          flow = (basis * weight_total).sum(1).reshape(bs, 2, h_patch, w_patch)
          inter_flows.append(flow)
      return flow, inter_flows

  NOTES:
   - h_net (SwinTransformer.forward) already takes a 2-channel [B,2,h,w] input
     (cat of two 1-ch features). Re-warping fea_tgt before the call is the only change.
   - The inner multi-scale loop (transformerHomo.py:414-437) keeps working; it now
     refines a residual rather than the full flow.
   - Accumulate WEIGHTS (basis coefficients), recompute flow from the running sum.
     This keeps everything in basis space, which is what flow_mask_to_homography expects.

4.3 Rewire HomoNet.forward (transformerHomo.py:1337-1344) to call the helper:

  H_flow_f, inter_flows_f = self._estimate_flow_iter(img1_patch_fea, img2_patch_fea, h_patch, w_patch)
  H_flow_b, inter_flows_b = self._estimate_flow_iter(img2_patch_fea, img1_patch_fea, h_patch, w_patch)

  Backward compatibility: with refine_iters==1 and detach_between irrelevant, this is
  IDENTICAL to today's single-shot estimate (one h_net call, no re-warp).

4.4 Intermediate supervision (training only).
  In HomoNet.forward, when self.training and refine_supervision, build per-iteration
  warped FEATURE maps for the triplet loss and stash them in the output dict:

    if self.training and _param_bool(self.params, "refine_supervision", True):
        warp_img2_fea_iters = [get_warp_flow(img2_full_fea, f, start) for f in inter_flows_f]
        warp_img1_fea_iters = [get_warp_flow(img1_full_fea, f, start) for f in inter_flows_b]
        output["warp_img2_patch_fea_iters"] = warp_img2_fea_iters
        output["warp_img1_patch_fea_iters"] = warp_img1_fea_iters
    # final-iteration warps remain exactly as today (lines 1346-1358), using inter_flows_*[-1].

  Cost: 2*T size-preserving feature warps (T~4) — cheap.

4.5 Extend compute_homography_loss (train_new.py:150) to sum over iterations:

    iters_f = output.get("warp_img1_patch_fea_iters")     # positives for forward triplet
    iters_b = output.get("warp_img2_patch_fea_iters")
    if iters_f is not None and use_intermediate:
        T = len(iters_f); gamma = args.refine_gamma
        align_f = align_b = 0.0
        for t in range(T):
            w = gamma ** (T - 1 - t)
            align_f = align_f + w * masked_triplet_alignment_loss(
                anchor=img2_fea, positive=iters_f[t], negative=img1_fea, mask=trusted_f)
            align_b = align_b + w * masked_triplet_alignment_loss(
                anchor=img1_fea, positive=iters_b[t], negative=img2_fea, mask=trusted_b)
        # normalize by sum of weights so the loss scale is iteration-count invariant
        norm = sum(gamma ** (T - 1 - t) for t in range(T))
        forward, backward = align_f / norm, align_b / norm
    else:
        # existing single-flow path (unchanged)

  Keep FIL on the final warp only (as today). align_total = forward + backward + fil.

4.6 Eval path: unchanged.

6. MASK UPGRADE (4) -- SHARPEN THE DOMINANT-PLANE MASK
================================================================================

The mask helps PME in TWO places: it weights the triplet loss
(bidirectional_mask_intersection, train_new.py:157) AND it weights the DLT used at eval
(evaluate.compute_h_from_output, :172-176). Sharper, better-localized masks => lower PME.

6.1 Keep flow_matching mask available, but for the ACCURACY track prefer a deterministic,
    stable mask. Two options — implement both, default to whichever wins the ablation:
      (a) mask_method="flow_matching" but DETERMINISTIC: steps small, init="zero",
          single sample (NO K-sample averaging; sampling variance does not help PME).
      (b) mask_method="homogan_cnn": the existing ASPP mask_predictor (transformerHomo.py:
          1311-1323). This is literally HomoGAN's mask (the 0.50->0.39 lever) and is the
          lowest-variance choice. Strongly consider it as the default for accuracy.

6.2 Apply the mask to the DLT during TRAINING too, not just eval, when computing the
    refined flow->H consistency (optional, low weight). Not required for PME but aligns
    train/eval.

6.3 Mask must be applied at FINAL iteration's residual map. Keep
    bidirectional_mask_intersection on the final masks (as today).

6.4 Mask training signal (keep unsupervised):
    - pseudo_mask_from_residuals (losses_homo.py:133) stays the real-data target source.
    - Reduce circularity: build the pseudo target from the FINAL-iteration residual AND
      require forward/backward agreement (multiply seed_1 by warped seed_2), then confidence-
      filter. This is mask supervision only; no GT homography is used.

6.5 Do NOT force large masks. Keep mask_area_loss bounds (min 0.10-0.15, max 0.90-0.95);
    on hard pairs a smaller dominant support is correct.


================================================================================
7. (Optional, low-effort) NORMALIZED WEIGHTED DLT
================================================================================

geometry_homo.py:64-79 builds the DLT system on RAW pixel coordinates (no Hartley
normalization). For an iterative flow that deviates from an exact homography across
regions, normalization improves the SVD conditioning and can shave error on LF/SF.

Add new_approach/geometry_tip.py: weighted_normalized_dlt(flow, weights) that
  1) normalizes src and dst points (centroid to origin, mean distance sqrt(2)),
  2) solves the weighted system,
  3) denormalizes H = inv(T_dst) @ Hn @ T_src, normalizes by H[2,2],
  4) returns a fallback flag when conditioning is poor (then use identity / initial).
Wire evaluate.compute_h_from_output to call it behind a flag --normalized-dlt.
This is minor (numerical robustness), not a pillar — implement only after Sections 4-6.


================================================================================
8. SF TARGETING (5) -- SMALL-FOREGROUND ROBUSTNESS  (unsupervised)
================================================================================

SF is the worst gap (0.99 vs 0.42). SF = small moving foreground objects that violate
the single dominant homography. Two complementary, fully-unsupervised mechanisms:

8.1 Robust alignment residual (helps SF AND LF).
    The triplet loss (losses_homo.py:50) uses mean-abs residual; small outliers still
    contribute gradient. Add a robust option to masked_triplet_alignment_loss:
      - "charbonnier":  rho(x)=sqrt(x^2+eps^2)  on (ap - an), OR
      - "truncated":    zero the top-k% largest per-pixel residuals before averaging
                        (k ~ 10-20%), so a few outlier pixels cannot dominate.
    Add CLI: --align-robust {none,charbonnier,truncated}, --align-trunc-frac 0.15.
    Default to charbonnier for the SF/LF push.

8.2 Foreground-paste augmentation for the MASK (unsupervised w.r.t. homography).
    During joint training, with probability p_fg (~0.5), paste 1-4 SMALL random patches
    (sizes ~16-64 px; smaller than the existing synthetic dataset's 64-180) into img2_full
    BEFORE the forward pass, and record their binary paste mask M_fg.
    - These pasted regions are, by construction, NOT explained by the dominant homography.
    - Add a loss: push the predicted mask to ~0 inside M_fg (warped to the patch frame):
          L_fg = BCE(img2_patch_mask inside M_fg, 0)   (only inside M_fg)
    - This teaches the mask to reject small foreground, exactly the SF failure mode.
    - It uses only a known PASTE mask, never a GT homography -> still unsupervised-H.
    Implement as an augmentation hook in the Data loader OR inside train_homography_epoch
    before model(data_batch); the simplest is a transform in build_real_loader.
    Add CLI: --fg-paste-prob 0.5 --fg-paste-min 1 --fg-paste-max 4 --fg-size-min 16 --fg-size-max 64.

8.3 SF-aware synthetic mask pretraining.
    In run_synthetic_mask (train_new.py:401), add a small-outlier regime:
    set synthetic_min_outlier_size ~16, synthetic_max_outlier_size ~80, and increase
    synthetic_max_outliers to ~6 so the mask module sees many small distractors during
    Stage-0 mask pretraining.

8.4 Report per-category PME every eval so SF progress is tracked explicitly.

9. SCALED TRAINING (3)  -- TURN THE SMOKE TEST INTO A REAL RUN
================================================================================

The current recipe cannot reach even HomoGAN-class accuracy. Scale it.

9.1 Capacity
    embed_dim: 24 -> 32 (try 48 if GPU allows). Keep depths/heads or use
      depths=(2,4,6), heads=(3,12,24) (current) as a fine default.
    feature_channels: 1 -> 32 (Section 5).

9.2 Optimization
    - Batch size: 16 (or 8 + grad-accum x2). DataParallel/AMP if needed.
    - Optimizer: AdamW, weight_decay 1e-4.
    - LR SCHEDULER (currently ABSENT — add it): cosine decay with linear warmup
      (~1k steps). Wire torch.optim.lr_scheduler into run_real_training (train_new.py:445)
      and step per-iteration.
    - Two param groups (estimator vs mask) with different LRs in the joint stage:
        estimator (h_net + fea_extra): lr_homo
        mask_flow / mask_pred:         lr_mask (higher)
    - AMP (torch.cuda.amp) to fit batch 16 at embed_dim 32 + correlation.
    - grad_clip 1.0 (keep).

9.3 Iterations / schedule (the key change)
    Stage A (pretrain_homo, mask=none): lr_homo 4e-4, cosine, ~60k-100k iters,
      refine_iters=4, refine_supervision=True. Goal: strong mask-free flow.
    Stage B (joint, mask on):           lr_homo 1e-4 / lr_mask 2e-4, cosine,
      ~80k-150k iters. Add mask losses + FG augmentation (Section 8).
    (Optional Stage 0 first: synthetic_mask pretraining of the mask module, existing mode.)

    With Train_List.txt ~ 442k pairs, 1 epoch at batch 16 ~ 27.6k iters; ~3 epochs A +
    ~5 epochs B is in range. Use --max-steps-per-epoch only for debugging (set 0 for full).

9.4 LR for the iterative model: because refine_supervision sums T losses, the effective
    gradient is larger; if unstable, lower lr by ~2x or raise warmup to 2k.

================================================================================
12. MILESTONES & GO/NO-GO GATES (tie everything to the 0.34 target)
================================================================================

G1 (after core iterative + minimal training): AVG must DROP vs the single-shot baseline
   at matched iterations. If refine_iters=4 is not clearly better than refine_iters=1,
   debug detach/supervision/weighting before scaling. Expected band after short train:
   noticeably below 0.669; after Stage A full: approaching ~0.45-0.50.

G2 (after mask sharpening + Stage B short): AVG in the HomoGAN band (~0.38-0.42), with SF
   improving. If AVG is stuck > 0.5 with a trained mask, the estimator (not the mask) is
   the bottleneck — revisit Section 5 (correlation).

G3 (after correlation + full Stage A/B): AVG < 0.39 (beats HomoGAN) is the real checkpoint.
   Push for < 0.34 (beats RealSH). Per-category, watch LL and SF (historically hardest).

FINAL target: AVG < 0.34 on all 4200 pairs. Stretch: <= 0.31.

If G3 stalls at ~0.36-0.39 (HomoGAN class) and will not cross 0.34, the remaining levers
are: more refine_iters (6-8), larger corr_radius, embed_dim 48, longer Stage B, and a
second-stage flow refinement at full resolution. Do NOT reach for supervised data
generation (out of scope) without an explicit decision to change the contribution story.

================================================================================
14. RISKS & MITIGATIONS
================================================================================

R1 No working GPU -> scaled training infeasible. MITIGATION: fix env first (Section 2);
   this is a hard blocker, not optional.
R2 Iterative loop unstable / NaN. MITIGATION: refine_detach_between=True; lower lr;
   raise warmup; clip grads; start refine_iters=2.
R3 Correlation channel mismatch crashes h_net / DominantMaskFlow. MITIGATION: set
   in_chans exactly (5.2); keep mask condition on a 1-channel projection; assert shapes.
R4 Intermediate supervision overweights coarse iters. MITIGATION: gamma normalization (4.5);
   sweep gamma in {0.6,0.8,0.9}.
R5 FG-paste hurts clean (RE) accuracy. MITIGATION: keep paste prob <=0.5; only apply the
   FG mask loss inside the paste region; ablate with/without on RE.
R6 Mask collapse (all-ones or tiny). MITIGATION: keep mask_area bounds; two-stage (mask-free
   Stage A first); monitor mask_mean.
R7 Beating 0.34 not reached. MITIGATION: gates G1-G3 catch stalls early; escalate iters/
   capacity/training before changing scope.

16. ONE-LINE SUMMARY FOR THE AGENT
================================================================================

Wrap the existing single-shot 8-basis estimator in a T-step re-warp/residual loop with
intermediate triplet supervision (1), add a recomputed local correlation volume on widened
features (1b), sharpen and apply the dominant-plane mask to loss+DLT (4), add a robust
alignment loss plus unsupervised small-foreground paste augmentation (5), and train it for
real with a cosine-scheduled, properly-batched two-stage schedule (3) — preserving the
flow_f/flow_b/mask output keys so evaluate.py measures PME unchanged. Target AVG < 0.34.
